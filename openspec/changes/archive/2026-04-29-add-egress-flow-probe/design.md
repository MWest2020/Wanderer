# Design: Egress flow probe (eBPF)

## Component placement

```
internal/probe/egress/flow/
  flow.go              # Inspector implementation
  bpf/                 # CO-RE C source for the connect tracepoint
  bpf/connect.bpf.c
  bpf/bpf_bpfel.go     # generated by bpf2go
internal/probe/egress/classify.go  # already exists; reused
```

Build pipeline: `go generate ./internal/probe/egress/flow/...`
runs `bpf2go` to compile the C program and embed it. CI gains a
matrix entry that runs the generator and asserts the embedded
files are up to date.

## eBPF program shape

A single `tracepoint/syscalls/sys_enter_connect` program reads the
sockaddr from userspace, filters out AF_UNIX, and emits a perf
event with `(saddr, daddr, dport, pid, comm)`.

Userspace consumes the perf events for the configured window
(default 60s) and aggregates by `(daddr, dport)` to deduplicate
short bursts. For each unique destination it resolves the host
back via reverse DNS (best-effort), classifies via the existing
`egress.classify.Classify`, and emits a Finding.

## Finding shape

```
ProbeID: egress.flow.<category>     // e.g. egress.flow.object_storage
Subject: <host name or IP literal>
SourceModus: egress
Attributes:
  runtime: true
  destination_ip: "203.0.113.5"
  destination_port: 443
  process_name: "node"
  pid: 12345
  classifier_rule: "..."
  asn / country / organisation (when GeoLite2 wired)
```

## Failure modes

| Cause                              | Outcome                                                                |
| ---------------------------------- | ---------------------------------------------------------------------- |
| Kernel < 5.8 / no CO-RE BTF        | `egress.flow.unavailable` with `reason: kernel too old`               |
| `CAP_BPF` / `CAP_PERFMON` absent   | `egress.flow.unavailable` with `reason: insufficient capabilities`     |
| Program fails to verify            | `egress.flow.error` with the verifier log (truncated)                  |
| Reverse DNS times out per host     | Skip annotation, keep the IP-only Finding                              |

## Tests

- Loader unit test: open a tmp BPF objfile, attach, detach.
  CI's kernel must support BTF; otherwise the test SkipsIfShort.
- Aggregation unit test: feed synthetic perf events into the
  aggregator, assert dedup behaviour.
- Classification reuse: the existing classify_test.go still
  passes — no fork.

## Clever valkuil

1. **Capture full packets.** No. We see `connect()`, not data.
   That is the line.
2. **Tracepoint everything (sendmsg, write, sendto).** No. The
   value is destination jurisdiction; `connect()` is enough.
3. **Custom kernel module.** No. eBPF is the boring choice.

## Operational notes

The flow probe is opt-in. The recommended deployment:

- Run in a 60-second window every 15 minutes (≤ 7% duty cycle).
- Output is bounded by the perf-event ring buffer; the agent
  drops events on overflow and counts them via a
  `egress.flow.dropped` Finding.

## Stability + coverage

- `internal/probe/egress/flow` target coverage: 70% (the kernel
  surface is hard to test without a kernel).
